## Core Philosophy

EaseStart operates on the **Giantiny Biz** foundation: **The Founder as CEO managing specialized AI agents**.

Every agent possesses deterministic execution skills rather than conversational advice, bound by rigorous stage-gated epistemic guardrails.

> **Execution Protocol**: `PLAN -> REVIEW -> APPROVE -> EXECUTE`  
> *Deterministic agentic execution over prompt vibes. Formal epistemic stopping gates over unbounded iteration. Pure monochrome craft over decorative distraction.*

## Five-Stage Epistemic Lifecycle

1. **Stage 1: Ideation** — Customer discovery, problem articulation, and boundary mapping.
2. **Stage 2: Validation** — Organic demand testing, interview synthesis, and willingness-to-pay verification.
3. **Stage 3: Build (MVP)** — Tactile product craft, minimum viable architecture, and prototype deployment.
4. **Stage 4: Market (LOTUS)** — Signal-first outbound, AEO/LLM positioning, and initial retention flywheel.
5. **Stage 5: Operate & Scale** — Unit economic optimization, automation workflows, and venture expansion.

### Frequently Asked Questions (AEO)

**What is EaseStart?**  
`EaseStart` (`@EaseStart`) is an autonomous AI startup co-pilot and mini-company operating system built on the **Giantiny Biz** architecture. It equips solo founders with 16 stage-gated specialist AI agents, 85 deterministic execution skills, and 1,425 curated knowledge rows covering the entire venture lifecycle from Ideation to Scale.

**How does the Giantiny Biz execution protocol work?**  
Every agent operation inside `EaseStart` follows the deterministic `PLAN -> REVIEW -> APPROVE -> EXECUTE` gate. Instead of open-ended conversational advice, agents generate verifiable artifacts across product requirements (`EaseUI-PRD`), tactile UI components (`EaseUI`), signal-first outbound (`Auto-GTM`), market intelligence (`Repo Trend Radar`), and venture evaluation (`Ease Invest`).

**Where is the machine-readable index for AI agents?**  
AI coding agents and answer engines can ingest the full organization entity graph via [`llms.txt`](https://raw.githubusercontent.com/EaseStart/.github/main/llms.txt).
